## 1. 왜 사실이 모자란가 (맥락)

**정우인재개발원**(한국 회사)의 페이스북 페이지에 하루 한 건씩 글을 올립니다. 1순위 독자는 **이미 일본에 있는
베트남·미얀마·네팔 사람** 중 한국 유학을 생각하는 사람입니다. 글은 광고가 아니라 **사실 안내**이고, 모두 무료
상담 안내로 끝납니다.

이 저장소에는 규칙이 하나 있습니다. **`facts.json`에 있는 사실에서 온 수치만 글에 쓸 수 있습니다.** 검사가
한국어 원문의 금액·시간·비율 숫자를 모두 훑어, 그 글이 인용한 사실의 값 안에 그 숫자가 없으면 경고를 냅니다.
그래서 "유학생은 주 20시간 일할 수 있다"처럼 널리 돌아다니는 숫자도 1차 출처를 찾지 못해 **일부러 비워 둔**
상태입니다.

확인된 사실이 15건(법령·하이코리아 4건 + 등록금 11건)뿐이라, 2026-11 ~ 2027-01 세 달 87건은 같은
사실을 각도만 바꿔 다시 씁니다. 수치가 아예 없는 소재도 여러 개 넣었습니다. **사실이 늘어나면 쓸 수 있는
이야기가 늘어납니다.** 그게 이 일입니다.

## 2. "사실"이 되는 조건 (다섯 가지)

### 2-1. 1차 출처만

**출처로 쓸 수 있는 곳:**

| 종류 | 예 |
| --- | --- |
| 법령 원문 | 국가법령정보센터 `law.go.kr` (출입국관리법·시행령·시행규칙, 고등교육법 등) |
| 출입국·체류 안내 | 하이코리아 `hikorea.go.kr`, 법무부 `moj.go.kr` |
| 공공데이터 표준데이터 | 공공데이터포털 `data.go.kr` |
| 교육 공시 | 교육부 `moe.go.kr`, 대학알리미 `academyinfo.go.kr`, 한국장학재단 |
| 보험·세금 | 국민건강보험공단 `nhis.or.kr`, 국세청 `nts.go.kr` |
| 재외공관 | 주일본 대한민국 대사관·총영사관의 공식 사이트 |
| 그 대학 자신 | 대학 공식 홈페이지 — **그 대학에 관한 사실에 한해서만** |

**출처가 아닌 것:** 블로그, 유학원·에이전시, 뉴스 기사, 위키, 커뮤니티, 유튜브, 다른 나라 사이트의 한국 제도
설명, 검색 결과 요약문(스니펫). 1차 출처가 그 말을 하고 있지 않으면 **그 사실은 없는 것**입니다.

### 2-2. 주소를 직접 열어 눈으로 확인합니다

검색 결과만 보고 적지 않습니다. 그 주소를 열어 **그 문장을 찾고**, 원문을 그대로 `검토.원문인용`에 옮깁니다.
여기에 원문을 옮겨 두면 나중에 사람이 다시 확인할 때 주소만 열어 대조하면 됩니다.

법령 주소(`lsiSeq=...` 같은 것)는 **바뀌기 쉽습니다.** 그래서 값 끝의 대괄호에 **법령명 · 조항 · 개정일자**를
적습니다(§2-3). 주소가 죽어도 그 표시로 다시 찾을 수 있습니다.

### 2-3. 값은 혼자서 읽힙니다

`value`는 숫자 한 개가 아니라 **조건까지 담은 한두 문장**이고, 끝에 대괄호로 출처 표시를 붙입니다.

```
[기관 · 문서명, 조항 또는 기준연도, 데이터기준일자]
```

그 까닭: 숫자만 떼어 적으면 글 쓰는 쪽이 조건을 모르고 쓰게 됩니다. 지금 있는 등록금 사실이 "1년치, 학기당
아님", "전체 학과 가중평균이라 개인 납부액과 다를 수 있음", "입학금 별도"까지 값 안에 적어 둔 것이 그래서입니다.
형식 본보기는 **부록 B**에 전문이 있습니다.

**수치를 글에 쓸 수 있으려면, 그 숫자가 `value` 안에 자릿수 그대로 있어야 합니다.** 검사는 천 단위 쉼표는
무시하고, 소수는 정수부도 같은 수로 봅니다(`8,028,841.1원` → `8028841`도 `8028841.1`도 인정). 반올림하거나
단위를 바꾼 숫자(`803만원`)는 다른 수로 걸립니다. 그러니 **공시된 자릿수를 그대로** 적습니다.

### 2-4. 유효기한은 "다음 갱신 직전"입니다

- 값이 정해진 주기로 갱신되는 것(공시·통계): **다음 공시가 나오기 직전 날짜**. 지금 등록금 사실은
  `2027-02-28`입니다.
- 갱신 주기가 없는 것(법령 조문, 제도 설명): **확인일 + 1년**. 지금 법령·하이코리아 사실이 그렇습니다.
- 유효기한은 **각 게시물의 게시일**로 판정합니다. 오늘 유효해도 게시일에 만료되면 오류입니다.
- **2027-01-30보다 먼저 끝나는 사실은 지금 계획에 쓸 수 없습니다**(마지막 게시일). 그런 사실도 적어 두되
  `검토`에 그렇게 적습니다.

### 2-5. 못 찾으면 못 찾았다고 적습니다

찾다가 1차 출처가 없으면 **그것도 결과**입니다. `output/facebook/fact-candidates-보고.md`에 무엇을 어디까지
찾았고 왜 못 찾았는지 적습니다(§7). 숫자를 지어내거나, 비슷한 2차 출처로 메우거나, "아마 이럴 것"이라고
적는 것은 이 일에서 가장 큰 사고입니다 — 그 숫자가 아무도 읽지 못하는 현지어로 나갑니다.

## 3. 쓰는 자리 — 후보 파일

**`output/facebook/facts.json`을 직접 고치지 마세요.** 그 파일은 "사람이 확정한 사실"이고, 거기에 들어간
순간부터 글에 쓸 수 있는 수치가 됩니다. 기계가 찾은 것은 아직 확정이 아니므로 **후보 파일**에 적고, 사장님이
확인한 뒤 옮깁니다.

- 쓸 파일: **`output/facebook/fact-candidates.json`** (지금은 `{}` 하나만 들어 있습니다)
- 모양: `facts.json`과 같고, 거기에 `검토` 항목 하나가 더 붙습니다. 저장소의 사실 로더가 추가 항목을 무시하므로
  **같은 검사를 그대로 통과**합니다. 옮길 때는 `검토`만 지웁니다.

한 건의 모양(이대로 베껴 쓰면 됩니다):

```json
{
  "foreign_registration_deadline": {
    "value": "<조건까지 담은 한두 문장> [기관 · 문서명, 조항 또는 기준연도, 데이터기준일자]",
    "source_url": "https://...",
    "verified_by": "codex",
    "verified_on": "2026-11-02",
    "expires_on": "2027-11-02",
    "검토": {
      "질문": "이 사실이 대답하는 질문 한 줄",
      "원문인용": "출처 문서에서 그대로 옮긴 문장(번역하지 않고 원문)",
      "다시확인하는법": "그 주소에서 어디를 보면 이 문장이 나오는지 (예: 별표 1의2 → 5. 유학(D-2))",
      "열어주는소재": "이 사실이 있으면 쓸 수 있는 글 한 줄",
      "메모": "애매한 점·주의할 점. 없으면 빈 문자열"
    }
  }
}
```

**키 이름 규칙**

- 영문 소문자·숫자·`_`만. 뜻이 보이게 짓습니다(`visa_d2_definition`, `part_time_work_permit_required`).
- 등록금은 반드시 **`tuition_<대학 id>`**. 그리고 그 `<대학 id>`가 `output/facebook/universities.json`에
  없으면 **거기에도 `{"id": "...", "name_ko": "..."}`를 더해야 합니다.** 그러지 않으면 그 대학 이름을 글에
  쓸 때 "승인된 대학 목록에 없다"는 오류가 납니다. 두 파일을 같이 고치세요.
- 이미 있는 키와 겹치면 안 됩니다(부록 A).

## 4. 검사하는 법

아래를 그대로 실행하면 **저장소의 진짜 사실 로더**로 후보 파일을 검사하고, 중복·형식·유효기한까지 함께
봅니다. 새 검사 코드를 쓴 것이 아니라, 나중에 `facts.json`을 판정할 바로 그 코드입니다.

```bash
python3 - <<'PY'
import json, pathlib, re, sys
sys.path.insert(0, "scripts")
from facebook.facts import FactsError, load_facts

CAND = pathlib.Path("output/facebook/fact-candidates.json")
LAST_POST_DAY = "2027-01-30"
GOOD_HOSTS = ("law.go.kr", "hikorea.go.kr", "moj.go.kr", "data.go.kr", "moe.go.kr",
              "academyinfo.go.kr", "kosaf.go.kr", "nhis.or.kr", "nts.go.kr",
              "overseas.mofa.go.kr", "mofa.go.kr", "ac.kr")
NEED = ("질문", "원문인용", "다시확인하는법", "열어주는소재")

raw = json.loads(CAND.read_text(encoding="utf-8"))
facts = json.loads(pathlib.Path("output/facebook/facts.json").read_text(encoding="utf-8"))
unis = {u["id"] for u in json.loads(
    pathlib.Path("output/facebook/universities.json").read_text(encoding="utf-8"))}

try:
    loaded = load_facts(CAND)          # 값·출처·확인자·확인일·유효기한의 형식 검사(저장소 코드)
except FactsError as exc:
    print("형식 실패:", exc)
    raise SystemExit(1)

bad = []
for key, entry in raw.items():
    if key in facts:
        bad.append(f"{key}: 이미 facts.json에 있습니다")
    if not re.fullmatch(r"[a-z0-9_]+", key):
        bad.append(f"{key}: 키는 영문 소문자·숫자·_ 만 씁니다")
    if key.startswith("tuition_") and key[len("tuition_"):] not in unis:
        bad.append(f"{key}: universities.json에 '{key[len('tuition_'):]}' id가 없습니다 (같이 더하세요)")
    if not re.search(r"\[[^\[\]]+\]\s*$", entry["value"]):
        bad.append(f"{key}: 값 끝에 대괄호 출처 표시가 없습니다")
    if not any(h in entry["source_url"] for h in GOOD_HOSTS):
        bad.append(f"{key}: 1차 출처로 보기 어려운 주소입니다 — {entry['source_url']}")
    review = entry.get("검토")
    if not isinstance(review, dict):
        bad.append(f"{key}: 검토 항목이 없습니다")
    else:
        for field in NEED:
            if not str(review.get(field, "")).strip():
                bad.append(f"{key}: 검토.{field} 항목이 비었습니다")
    if entry["expires_on"] < LAST_POST_DAY:
        bad.append(f"{key}: 유효기한 {entry['expires_on']}이 마지막 게시일({LAST_POST_DAY})보다 빠릅니다"
                   f" — 지금 계획에는 쓸 수 없습니다(적어는 두세요)")

print(f"후보 {len(loaded)}건 · 형식 통과")
if bad:
    print("문제 " + str(len(bad)) + "건:")
    for line in bad:
        print("  " + line)
    raise SystemExit(1)
print("문제: 없음")
PY
```

마지막에 `문제: 없음`이 나오면 넘길 준비가 된 것입니다. 문제가 있으면 끝난 코드가 `1`이므로, 여러 번 돌리는
자리에서는 그 코드로 판단해도 됩니다.

> 모든 명령은 저장소 뿌리 폴더(`nepal-school`)에서 돌립니다. 가지(branch)는
> `worktree-facebook-daily-posting`입니다. `cd ~/nepal-school && git branch --show-current` 로 확인하세요.

## 5. 찾아야 할 것 (우선순위대로)

아래 순서는 **독자가 가장 많이 묻는 것**과 **수확이 가장 큰 것**을 섞어 매긴 것입니다. 1번이 제일 큽니다.

### 1. 등록금 — 학교를 늘립니다 (가장 큰 수확)

지금 11개 학교뿐입니다. 출처가 **공공데이터포털의 표준데이터 한 개 파일**(한국장학재단
전국대학별평균등록금정보)이라, 같은 파일에서 수십 개 학교를 같은 형식으로 뽑을 수 있습니다.

- 뽑을 것: `대학·본교` 구분의 **연간 평균등록금**과 **평균입학금액**, 기준연도, 데이터기준일자.
- 키: `tuition_<대학 id>` — `universities.json`에도 그 id와 한국어 이름을 같이 더합니다.
- 값의 문장은 **부록 B를 그대로 본보기로** 씁니다(1년치·가중평균·입학금 별도 문구를 빼지 마세요).
- 어느 학교를 더할까: 외국인 유학생을 받는 학교 중 **수도권 사립·지방 국립·전문대학**이 섞이게 고릅니다.
  지금 목록(경기대학교, 평택대학교, 협성대학교, 호남대학교, 청주대학교, 우석대학교, 전주기전대학, 전북대학교, 위덕대학교, 제주한라대학교, 제주관광대학교)과 겹치지 않는 학교로 **20~40개**를 목표로 합니다.
- 주의: 같은 이름의 다른 학교(본교·분교, `○○대학교`와 `○○대학`)가 있습니다. 표준데이터의 학교 구분을
  그대로 적고, 애매하면 `검토.메모`에 적습니다.

### 2. 유학생 시간제취업(아르바이트) 허용 시간

**이 페이지에서 가장 많이 묻는 것인데 지금 비어 있습니다.** "주 20시간"이라는 말이 널리 돌아다니지만 1차
출처를 확인하지 못해 일부러 넣지 않았습니다. 허용 시간은 학위과정·한국어 능력·성적·학기/방학에 따라 달라집니다.

- 찾을 곳: 하이코리아의 체류자격외활동(시간제취업) 안내, 법무부 체류관리 지침.
- **숫자 하나만 적지 마세요.** 조건별 표 전체를 값에 담습니다(과정 구분 · 어학 요건 · 학기 중 주당 시간 ·
  방학 중). 조건을 못 떼어 적을 수 없으면, 그 사실은 아직 쓸 수 없는 것입니다.
- 키 제안: `part_time_hours_by_level`

### 3. 유학 사증 신청 때 보여야 하는 재정능력

"얼마가 있어야 갈 수 있나"가 등록금 다음으로 많이 묻는 것입니다.

- 찾을 곳: 하이코리아 사증발급 안내(유학), 재외공관의 유학사증 안내.
- 금액·통화·기준 시점(언제의 잔고인지)·과정별 차이를 값에 담습니다.
- 키 제안: `financial_requirement_d2`

### 4. D-2에 하위 분류가 있는가

`D-2-1`, `D-2-2` 같은 하위 구분이 있다는 말이 돌아다닙니다. **실제로 그렇게 나뉘는지, 나뉜다면 어떤 기준으로
나뉘는지**를 1차 출처에서 확인하세요. 독자가 자기 자리를 찾는 데 쓰입니다.

- 찾을 곳: 출입국관리법 시행령 별표 1의2, 법무부·하이코리아의 체류자격 분류.
- 하위 구분이 **법령에 없고 행정 분류일 뿐**이라면 그것도 적을 만한 결과입니다.
- 키 제안: `visa_d2_subtypes`

### 5. 외국인등록 기한

입국한 뒤 며칠 안에 외국인등록을 해야 하는지, **그리고 늦으면 어떻게 되는지**. 날짜가 걸린 사실이라 독자가
바로 쓰게 됩니다.

- 찾을 곳: 출입국관리법의 외국인등록 조문, 하이코리아.
- 기한과 불이익(있다면)을 **같은 값 안에** 담습니다. 불이익 쪽 근거를 못 찾으면 기한만 적습니다.
- 키 제안: `foreign_registration_deadline`

### 6. D-4(일반연수·어학연수) 학생의 시간제취업 조건

D-2와 조건이 다릅니다(입국 후 일정 기간이 지나야 한다는 말이 있는데 확인되지 않았습니다).

- 찾을 곳: 하이코리아 시간제취업 안내의 D-4 부분.
- 키 제안: `part_time_d4_condition`

### 7. 학년도는 언제 시작하는가

"3월 입학·9월 입학"이라는 말이 널리 쓰입니다. **법령이 학년도 개시일을 어떻게 정하고 있는지**를 확인하세요.
입학 시기에서 거꾸로 세어 준비 일정을 말하는 글(1월 소재 중 하나)이 여기에 기댑니다.

- 찾을 곳: 고등교육법 및 그 시행령의 학년도 조문.
- 학교가 달리 정할 수 있게 되어 있다면, 그 여지까지 값에 적습니다.
- 키 제안: `academic_year_start`

### 8. 국민건강보험 당연가입

유학생도 건강보험에 들어가는지, 언제부터, 보험료는 어떻게 정해지는지.

- 찾을 곳: 국민건강보험공단의 외국인 가입 안내, 국민건강보험법.
- 키 제안: `health_insurance_enrollment`

### 9. 일본에서 한국 유학사증을 신청하는 길

1순위 독자가 **일본에 있는 사람**입니다. 일본에서 바로 신청할 수 있는지, 어디서 받는지가 핵심입니다.

- 찾을 곳: 주일본 대한민국 대사관 및 각 총영사관의 사증 안내 페이지.
- 주의: 공관마다 다를 수 있습니다. 공통인 것만 사실로 적고, 다른 점은 `검토.메모`에 적습니다.
- 키 제안: `visa_apply_in_japan`

### 10. 체류기간 연장 신청 기간

- 찾을 곳: 출입국관리법 시행규칙, 하이코리아.
- 키 제안: `extension_application_window`

### 11. 교육국제화역량 인증대학(IEQAS)

인증 여부에 따라 사증 심사가 달라진다면, "어느 학교를 고를까"에 바로 쓰입니다.

- 찾을 곳: 교육부 보도자료·공고의 인증대학 명단과 그 효과.
- 주의: 명단은 해마다 바뀝니다. 유효기한을 짧게 잡으세요.
- 키 제안: `ieqas_certification`

### 12. 생활비 (어려움 · 마지막)

"한 달에 얼마 드나"는 가장 많이 묻지만 **1차 출처가 가장 약합니다.** 정부 통계가 "유학생 생활비"를 그대로
공시하지 않습니다. 기숙사비처럼 **학교가 공시하는 항목**이라면 대학알리미에서 찾을 수 있습니다.

- 억지로 만들지 마세요. 못 찾으면 못 찾았다고 적는 쪽이 낫습니다.
- 키 제안: `dormitory_fee_<대학 id>`

## 부록 B. 형식 본보기 — 등록금 사실 한 건 전문

새로 적는 값은 이만큼 자세해야 합니다. 숫자만 있고 조건이 없는 값은 글 쓰는 쪽을 틀리게 만듭니다.

```json
{
  "tuition_jeonbuk": {
    "value": "연간 평균등록금 4,461,484.3원(1년치, 학기당 아님). 전체 학과 가중평균으로 산출한 공시 평균값이므로 학생 개인의 실제 납부액과 다를 수 있다. 입학금은 별도 공시 항목이라 이 금액에 포함되지 않는다(해당 학교(본교) 평균입학금액 0원). [한국장학재단 전국대학별평균등록금정보 표준데이터, 대학·본교, 기준연도 2026, 데이터기준일자 2026-05-19]",
    "source_url": "https://www.data.go.kr/data/15107738/standard.do?colCondition=UNIV_NM&searchKeyword1=%EC%A0%84%EB%B6%81%EB%8C%80%ED%95%99%EA%B5%90",
    "verified_by": "builder",
    "verified_on": "2026-10-31",
    "expires_on": "2027-02-28"
  }
}
```

읽는 법:

- `value`가 **숫자 + 단위 + 조건 + 대괄호 출처 표시**로 되어 있습니다. 대괄호 안에 기관·문서명·기준연도·
  데이터기준일자가 있어서, 주소가 죽어도 다시 찾을 수 있습니다.
- `4,461,484.3원`처럼 **공시된 자릿수를 그대로** 적었습니다. 검사가 글의 숫자를 이 값과 대조합니다.
- `expires_on`이 `2027-02-28`입니다 — 다음 공시가 나오기 직전입니다.
- "1년치, 학기당 아님", "개인 납부액과 다를 수 있다", "입학금 별도"가 값 안에 있습니다. 이 한정이 빠지면
  글에서 학기당 금액이나 정확한 금액으로 읽힙니다.
