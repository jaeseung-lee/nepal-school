## 1. 이 그림이 어디에 쓰이는가 (맥락)

**정우인재개발원**(한국 회사)의 페이스북 페이지에, **하루에 한 건씩** 사진 1장 + 글 1편을 올립니다. 글은 이미
다 써 두었고(저장소의 `plan.json`), **비어 있는 것은 사진뿐**입니다.

**누가 보는가.** 1순위는 **이미 일본에 있는 베트남·미얀마·네팔 사람** 중 한국 유학을 생각하는 사람입니다.
그래서 글은 한국어가 아니라 **베트남어·미얀마어·네팔어**로 올라갑니다. 한 소재를 사흘에 걸쳐
**베트남어 → 미얀마어 → 네팔어** 순서로 하루 한 건씩 올립니다. 같은 소재의 세 장은 **같은 그림이 아니라,
같은 분위기의 다른 각도**여야 합니다(그래서 프롬프트가 세 개 다 다릅니다).

**무슨 이야기를 하는가.** D-2·D-4 체류자격, 시간제 아르바이트 허가, 한국 대학의 1년 평균 등록금 같은
**사실 안내**입니다. 광고 문구나 약속은 한 줄도 없습니다. 글은 모두 "무료 상담 안내"로 끝납니다.

**그래서 그림은 이런 그림이어야 합니다.** 조용한 편집 삽화(flat vector), 중성적인 색, 여백이 넉넉하고,
도형으로 뜻을 전하는 그림. 사람 사진 같은 것, 광고 배너 같은 것, 글자가 박힌 카드뉴스 같은 것은 **아닙니다**.
프롬프트에 이미 그렇게 적혀 있으니 **프롬프트를 고치지 말고 그대로 쓰면 됩니다**.

## 2. 만들 것 — 이름이 전부다

파일 이름은 `번호-소재-언어.png` 입니다. 예: `00-visa-d2-vi.png`.

- 번호는 그 달 안에서 00부터 이어집니다(두 자리, 0을 채웁니다).
- 언어는 `vi`(베트남어) · `my`(미얀마어) · `ne`(네팔어)입니다.
- **확장자는 `.png`입니다.** `.jpg`로 저장하면 그 장은 "없는 것"으로 처리됩니다.

전체 목록은 **부록 A**에 날짜·언어·프롬프트까지 적혀 있습니다. 목록은 저장소에서 직접 뽑을 수도 있습니다:

```bash
npm run fb:images -- --month 2026-11
```

(`2026-11` 자리에 `2026-12`, `2027-01`을 넣어 세 번 돌리면 됩니다. `--`를 빼지 마세요.)

## 3. 반드시 지킬 네 가지

이 네 가지는 취향이 아니라 **검사 조건**입니다. 하나라도 어긋나면 그 달 게시가 멈춥니다(§3-5).

### 3-1. 글자가 한 글자도 없어야 합니다

프롬프트마다 `no text, no letters, no logos` 가 글자 그대로 들어 있습니다. **지우지 마세요.**

까닭: 그림 도구는 미얀마 문자와 데바나가리(네팔어)를 거의 반드시 깨뜨려 그립니다. 깨진 글자가 박힌 그림이
현지 독자에게 올라가면, 글을 아무리 공들여 써도 그 한 장으로 신뢰가 끝납니다. 영어 글자도 안 됩니다.
간판·책 표지·화면 속 글자·워터마크·서명도 글자입니다.

### 3-2. 실제 인물·실제 대학 캠퍼스·회사 시설처럼 보이면 안 됩니다

프롬프트마다 `no real people, no real campuses, no company facilities` 가 글자 그대로 들어 있습니다.
**지우지 마세요.**

까닭: 이 글들은 사실 안내입니다. AI가 만든 그림이 **실제 기록 사진으로 읽히면** 그 자체가 거짓이 됩니다.
특정 대학의 건물처럼 보이는 그림은 "그 대학과 관계가 있다"는 오해까지 만듭니다(글에서는 그런 말을 한 줄도
하지 않습니다). 사람은 **얼굴 없는 도형·실루엣**까지만 허용하고, 사진처럼 보이는 인물은 다시 만듭니다.

### 3-3. 파일 이름이 글자까지 같아야 합니다

`00-visa-d2-vi.png` 와 `00-visa-d2-vi (1).png` 는 **다른 파일**입니다. 뒤쪽은 폴더에 있어도 "없는 것"으로
처리됩니다. 그림 도구가 붙이는 `(1)`, `-1`, `copy`, 대문자, 공백을 **전부 떼고** 저장하세요.

### 3-4. `.png` · 0바이트 아님 · 8MB 이하

- 확장자 `.png`
- 파일 크기가 0이 아닐 것(저장이 중간에 끊기면 0바이트가 됩니다)
- **8MB(8,388,608바이트) 이하**. 평면 삽화는 보통 1MB 아래입니다.
- 비율은 **정사각형(1:1)**, 한 변 **1200px 이상**을 권합니다(1600px 권장). — 이 숫자는 검사 조건이 아니라
  작업 지침입니다. 페이스북에서 잘리지 않게 하려는 것입니다.

### 3-5. 왜 한 장이 빠지면 전체가 멈추는가

예약 도구는 **그 달의 오류가 0건이어야 한 건도 올립니다**. 그림 한 장이 없으면 그 한 건만 빠지는 것이
아니라 **그 달 30건이 통째로 예약되지 않습니다**(연습 실행조차 멈춥니다). 29장을 잘 만들고 1장을 빠뜨리면
그 달은 0장입니다. 그래서 **전수**가 중요합니다.

## 4. 작업 순서

### 4-1. 저장소를 받습니다

저장소 이름은 `nepal-school`, 쓸 가지(branch)는 **`worktree-facebook-daily-posting`** 입니다.
이 가지에 세 달치 `plan.json`과 이 문서가 들어 있습니다.

확인:

```bash
ls output/facebook/2026-11/plan.json output/facebook/2026-12/plan.json output/facebook/2027-01/plan.json
```

세 줄이 다 보이면 준비된 것입니다.

**필요한 도구.** 그림을 만드는 일 자체에는 `python3`만 있으면 됩니다(§4-4·§4-6의 명령이 그것만 씁니다).
다만 **마지막 검사(§4-7)에는 `uv`가 필요**합니다. `npm run ...` 꼴을 쓰려면 `node`도 있어야 합니다
(`npm`은 Node와 함께 깔립니다). 확인:

```bash
uv --version
node --version
```

`uv: command not found`가 나오면 아래 한 줄로 설치하고 터미널을 새로 연 뒤 다시 확인합니다.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

`node`가 없으면 `npm run` 대신 같은 일을 하는 아래 꼴을 쓰면 됩니다(`uv`만 있으면 돕니다).

```bash
uv run --script scripts/facebook-cli.py validate --month 2026-11
uv run --script scripts/facebook-cli.py images --month 2026-11
```

`uv`를 처음 돌릴 때는 파이썬과 부품을 받아 오느라 몇 분 걸립니다. 화면이 멈춘 것처럼 보여도 기다리세요.
저장소 뿌리의 `npm install`은 이 작업에 필요하지 않습니다.

### 4-2. 후보를 둘 폴더를 저장소 **밖에** 만듭니다

```bash
mkdir -p ~/fb-후보/2026-11 ~/fb-후보/2026-12 ~/fb-후보/2027-01
```

변형 3장은 여기에 `00-visa-d2-vi-1.png`, `-2`, `-3` 처럼 둡니다. **저장소 안에 두지 마세요** — 섞이면
어느 것이 채택본인지 알 수 없게 되고, 진행 확인 명령이 "플랜이 모르는 파일"로 잡아냅니다.

### 4-3. 최종본을 둘 폴더를 만듭니다

```bash
mkdir -p output/facebook/2026-11/images output/facebook/2026-12/images output/facebook/2027-01/images
```

### 4-4. 한 장씩: 변형 3장 → 1장 채택

1. 부록 A(또는 `plan.json`의 `image_prompt`)의 프롬프트를 **그대로** 씁니다. 말을 보태거나 줄이지 않습니다.
2. 같은 프롬프트로 3장을 뽑아 `~/fb-후보/<월>/`에 둡니다.
3. §4-5의 세 가지를 눈으로 보고 1장을 고릅니다.
4. 고른 1장을 `output/facebook/<월>/images/` 에 **적힌 이름 그대로** 복사합니다.

프롬프트를 기계로 읽으려면:

```bash
python3 -c "
import json
for m in ('2026-11','2026-12','2027-01'):
    plan = json.load(open(f'output/facebook/{m}/plan.json', encoding='utf-8'))
    for p in plan['posts']:
        print(m, p['image_file'], p['image_prompt'], sep='\t')
" | head -3
```

### 4-5. 그림 한 장마다 눈으로 보는 세 가지

- **글자가 보이는가** — 한 글자라도 보이면 버리고 다시 만듭니다(§3-1).
- **실제 사진처럼 보이는가** — 실제 인물·특정 대학 건물·회사 시설처럼 보이면 버립니다(§3-2).
- **같은 소재의 세 장이 서로 다른가** — vi·my·ne 세 장이 거의 같은 그림이면, 사흘 연속 같은 그림을 올리는
  셈이 됩니다. 프롬프트의 마지막 한 문장(각도·구도)이 서로 다르니, 그 차이가 보이는 쪽을 고릅니다.

### 4-6. 진행 확인 (하루 끝에, 그리고 월을 마칠 때)

아래를 그대로 실행하면 **몇 장 들어왔는지**와 **이름이 틀린 파일**을 함께 보여 줍니다. 틀린 이름은
`fb:validate`가 "없다"고만 말하기 때문에, 이 확인이 "만들었는데 왜 없다고 하지"를 막아 줍니다.

```bash
python3 - <<'PY'
import json, pathlib
MAX = 8 * 1024 * 1024
for month in ("2026-11", "2026-12", "2027-01"):
    d = pathlib.Path("output/facebook") / month
    plan = json.loads((d / "plan.json").read_text(encoding="utf-8"))
    want = [p["image_file"] for p in plan["posts"]]
    img = d / "images"
    have = {f.name for f in img.iterdir() if f.is_file() and not f.name.startswith(".")} if img.is_dir() else set()
    missing = [n for n in want if n not in have]
    stray = sorted(have - set(want))
    bad = [(n, (img / n).stat().st_size) for n in want if n in have
           and not (0 < (img / n).stat().st_size <= MAX)]
    print(f"[{month}] {len(want) - len(missing)} / {len(want)}장")
    if missing:
        print("  없음:", ", ".join(missing))
    if stray:
        print("  플랜이 모르는 파일(이름 확인):", ", ".join(stray))
    if bad:
        print("  크기 문제:", ", ".join(f"{n} {s:,}바이트" for n, s in bad))
PY
```

세 달 모두 `30 / 30`(11월은 `27 / 27`)이고 아래 줄이 없으면 끝난 것입니다.

### 4-7. 마지막 검사 (저장소에서 할 수 있는 확인)

```bash
npm run fb:validate -- --month 2026-11
```

- **그림을 다 넣기 전:** 오류가 그 달의 게시물 수만큼 나옵니다. 전부 `이미지없음`이면 정상입니다.
  다른 종류의 오류가 보이면 **글이나 플랜에 손을 댄 것**입니다(§5-2).
- **다 넣은 뒤:** `오류 0건, 경고 0건` 이 나와야 합니다.

세 달 모두 0건이면 작업 완료입니다.

## 5. 하지 말 것

### 5-1. 예약 명령을 실행하지 마세요

`npm run fb:schedule ...` 는 **실제 페이스북에 예약을 올리는 명령**입니다. 이 작업과 무관하고, 되돌리기가
번거롭습니다. 예약은 사업주가 자기 맥에서 직접 합니다.

### 5-2. `plan.json`을 고치지 마세요

날짜·순서·파일 이름·본문이 모두 검사를 통과한 상태입니다. 한 글자만 고쳐도 다른 오류가 줄줄이 납니다.
그림 이름이 마음에 들지 않더라도 **플랜을 고치는 대신 플랜의 이름을 따르세요**.

### 5-3. 토큰은 필요하지 않습니다

이 작업에는 페이스북 토큰이 **전혀** 필요하지 않습니다. `.env` 파일을 만들지도, 어디서 토큰을 받아오지도
마세요. 토큰은 사업주의 맥에만 있습니다.

### 5-4. 그림을 git에 커밋하지 마세요

`output/facebook/*/images/` 는 저장소에서 **일부러 제외**되어 있습니다(`.gitignore`). 그림은 git이 아니라
**폴더째 옮기는** 쪽으로 설계된 것입니다. `git add -f` 로 억지로 넣지 마세요.

돌려줄 때는 `images` 폴더 3개를 그대로 복사해 전달합니다(USB·AirDrop·클라우드 드라이브 등). 받는 쪽은
자기 저장소의 같은 경로(`output/facebook/<월>/images/`)에 덮어씁니다.

### 5-5. 글(본문)을 손대지 마세요

베트남어·미얀마어·네팔어 본문은 아직 **원어민 검수를 받지 않은 상태**이고, 그 검수는 사업주가 따로
진행합니다. 읽다가 어색한 곳이 보이면 **고치지 말고 적어서 알려 주세요**.

## 7. 완료 기준 (이 네 줄이 다 참이어야 합니다)

1. 세 달의 `images/` 폴더에 각각 27·30·30장이 있고, 이름이 플랜과 글자까지 같다.
2. 모든 그림에 글자가 없고, 실제 인물·캠퍼스·시설처럼 보이지 않는다.
