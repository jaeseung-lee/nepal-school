‘1.3 단계별 서비스 범위’ 제목에 ‘추진 체계와’를 추가하고, 기존 세 설명 문단 다음에 완성 도식 한 장을 삽입했다. 기존 빈 문단을 사용하여 추가 캡션을 만들지 않았다. 본문 너비 481.8755905511811pt에 맞춘 정사각형 이미지이며 가운데 정렬, 문단 위 8pt·아래 12pt 간격을 적용했다.

Google Docs API의 새 이미지 ID는 `kix.8a3zoctpj0a5`다. 제목 추가 문구를 제외한 본문, 기존 제목 ID, 링크, 기존 이미지 13개를 보존했고 총 이미지 14개를 확인했다. 이미지의 임시 조회 URL을 제외하고 기존 이미지의 속성과 원본 URI가 동일하다.

PDF로 확인한 문서는 32쪽이다. 새 도식은 5쪽 위에 하나의 이미지로 배치되며, 아래에 1.4 제목과 본문이 이어진다. 실제 5쪽 렌더에서 텍스트와 화살표의 잘림·겹침이 없고 본문 폭에 맞게 정렬되어 있다.
