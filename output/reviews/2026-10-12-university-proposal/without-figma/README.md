# Figma 도해 제거

2026년 10월 12일 사용자 요청에 따라 Google Docs에 삽입했던 Figma 도해 7개의 이미지 문단을 모두 삭제했습니다. Figma 원본 디자인 파일은 변경하지 않았습니다.

최신 Google Docs: https://docs.google.com/document/d/1Mmrct0UOPUhttx0aZrel5o_uA14CaxgzILpuAhU5ciY

삭제 직전 문서를 다시 읽어 사용자 변경사항을 포함한 최신 리비전을 기준으로 적용했습니다. 본문·75개 제목 ID·34개 링크를 보존했고, 실제 사진 8개·로고 1개·원본 PDF 부록 4쪽을 유지했습니다. 남은 인라인 이미지는 13개이며 Figma 도해는 0개입니다.

최종 PDF는 32쪽이며 빈 페이지·그림 캡션·이미지 영역 초과가 없습니다. 문서 내용 보존 검증은 `content-verification.json`, 페이지 배치 기록은 `pdf-layout.json`에 있습니다. PDF와 렌더 이미지는 검토용이며 Google Docs가 최종 전달 문서입니다.
