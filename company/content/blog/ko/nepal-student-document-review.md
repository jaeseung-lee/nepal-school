## 해당 학교의 최신 목록부터 확인합니다

요구 서류는 학교, 과정과 모집 시기에 따라 달라집니다. 최신 모집요강을 점검표로 사용하고 대사관 요건은 별도로 확인합니다. 현지 협력자는 자료 정리를 지원할 수 있지만 입학 결정은 교육기관이 합니다.

## 서류별 확인대장을 만듭니다

| 자료 | 기록할 내용 |
| --- | --- |
| 본인 확인 | 문서 간 성명 표기와 생년월일 |
| 학력 | 발급기관, 과정, 수료일과 요구 증빙 |
| 언어 | 해당 모집에서 인정하는 시험·교육 자료 |
| 재정 | 요구 형식, 발급기관과 유효 조건 |
| 번역 | 제출 언어, 인증 방식과 담당 기관 |

1. 동의를 받고 필요한 서류만 요청합니다.
2. 수령, 누락과 설명 필요 항목을 나누어 기록합니다.
3. 불일치는 지원자와 정당한 발급기관 경로로 확인합니다.
4. 남은 질문을 정리해 교육기관에 전달합니다.

## 협력자가 불일치 서류를 직접 고쳐도 되나요?

원본을 수정하거나 대체 증빙을 만들어서는 안 됩니다. 설명 또는 발급기관이 정정 발급한 서류를 요청합니다. 민감한 자료의 접근 범위와 보관 기간도 정합니다. 서류가 모두 모였다는 사실이 입학이나 비자 승인을 보장하지는 않습니다.
