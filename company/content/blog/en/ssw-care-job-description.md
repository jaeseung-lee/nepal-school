## Start with the actual work

The care field covers physical care and associated support activities. A vacancy labelled “care assistant” is too broad to show what the person will do. List the unit, people receiving care, shifts and reporting line, then compare each proposed task with the official field guidance.

## Use a task and supervision table

| Task | What the employer should specify |
| --- | --- |
| Assistance with daily living | Tasks, training and supervision required |
| Recreation support | Who plans the activity and assigns work |
| Records and handovers | Required language, format and checking person |
| Cleaning or other support | Connection to care work and expected allocation |

1. Ask the unit manager to describe a normal shift.
2. Identify tasks needing additional qualifications or training.
3. Remove unclear duties from the offer until their scope is confirmed.
4. Explain the final description in language the candidate understands.

Home-visit services need a separate check against current requirements; do not assume a facility job description covers them.

## Can one description cover every facility?

Use a shared format, but confirm duties for each workplace. An internal assessment does not authorize medical procedures. When duties change, recheck the permitted activities before assigning them.
