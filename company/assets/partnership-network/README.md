# 전국 활동·협력기관 자료

회사소개서 Canva 12·13페이지(2026-10-06 PowerPoint 다운로드)를 기준으로 작성했습니다.

- `logo-sources.json`: 13페이지 원본 28개 로고와 사이트 내부 파일의 대응 목록
- `korea-activities.excalidraw`: 12페이지의 대한민국 지도 윤곽과 편집 가능한 지역 표시
- `korea-activities-preview.svg`: 위 편집 파일의 SVG 미리보기
- 웹 지도는 `public/partners/maps/korea-activities.svg`와 언어별 링크를 조합합니다.

로고 원본의 색상과 비율을 유지하며 큰 이미지로 확대하지 않습니다. Sunkoshi와 Ocean 로고의 대응은 사용자가 확인했습니다. ENgate의 구체적인 협력 업무는 자료에 확인되지 않아 추가하지 않았습니다. 기존 MOU 자료 파일은 보존했습니다.

28개 로고는 회사소개서 원본을 사용하며, 표시 크기는 원본 해상도 이내로 제한합니다. 영문 기관명은 한영대학교, 제주관광대학교, 김포대학교, 전주기전대학의 공식 사이트 표기도 확인했습니다.

- 여섯 언어 × 메인·파트너십 × 390/768/1440px: 활동 21개, 로고 28개, 가로 넘침 없음
- 지도 링크 6개 모두 연결 대상 존재, 키보드 Enter로 이동 확인
