# 전국 활동·협력기관 자료

회사소개서 Canva 12·13페이지(2026-10-06 PowerPoint 다운로드)를 기준으로 작성했습니다.

- `logo-sources.json`: 13페이지 원본 28개 로고와 이후 확인된 기관 로고의 출처 및 사이트 내부 파일 대응 목록
- `korea-activities.excalidraw`: 12페이지의 대한민국 지도 윤곽과 편집 가능한 지역 표시
- `korea-activities-preview.svg`: 위 편집 파일의 SVG 미리보기
- 웹 지도는 `public/partners/maps/korea-activities.svg`와 언어별 링크를 조합합니다.

로고 원본의 색상과 비율을 유지하며 큰 이미지로 확대하지 않습니다. Sunkoshi와 Ocean 로고의 대응은 사용자가 확인했습니다. Engatesoft의 협력 업무는 2026-10-20 사용자 확인 후 추가했습니다(아래 참고). 기존 MOU 자료 파일은 보존했습니다.

28개 로고는 회사소개서 원본을 사용하며, 표시 크기는 원본 해상도 이내로 제한합니다. 영문 기관명은 한영대학교, 제주관광대학교, 김포대학교, 전주기전대학의 공식 사이트 표기도 확인했습니다.

## 추가 확인 (2026-10-17)

- 사용자 확인에 따라 협성대학교를 수도권 협력 대학에 `지원` 상태로 추가했습니다. 세부 과정은 별도로 확인되지 않아 기재하지 않았습니다.
- [협성대학교 공식 홈페이지](https://www.uhs.ac.kr/uhs/index.do)의 로고와 영문명 `Hyupsung University`를 사용합니다. 로고는 원본 크기 218×109px와 비율을 유지해 PNG로 변환했습니다.
- 현재 협력 대학은 13개, 전체 기관 로고는 29개입니다.

## 일본 협력기관 신설 (2026-10-20)

- 사용자 확인에 따라 `일본 협력기관` 묶음(`kind: "japan"`)을 새로 만들고, 기존 국내외 협력기관에 있던 Engatesoft를 이 묶음으로 옮겼습니다. 사용자 확인에 따라 설명은 `공장·개호시설 취업공고 접수·처리, 송입기관 및 등록지원기관`으로 적었습니다.
- 신규 협력기관 大阪なにわ日本語学校(大阪市浪速区大国3-12-18)를 추가했습니다. [공식 사이트](https://onjls.com/)의 헤더 로고와 영문명 `Osaka Naniwa Japanese Language School`을 사용하며, 로고는 원본 크기 337×83px와 비율을 유지해 PNG로 변환했습니다. 사용자 확인에 따라 당사가 이 학교의 공식 에이전시임을 설명에 적었습니다.
- 현재 국내외 협력기관은 6개, 일본 협력기관은 2개, 전체 기관 로고는 30개입니다.
