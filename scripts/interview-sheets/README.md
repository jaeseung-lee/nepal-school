# 일본어 면접 인쇄물 (네팔 현지 면접용)

특정기능1호(介護·宿泊) 후보 학생 대상 일본어 면접에 쓰는 A4 인쇄물 3종을 생성한다.
한국 대사관식 평가 방식 — 평가영역별 문항 풀에서 면접관이 랜덤으로 1문항씩 출제 — 을 전제로 한다.

| 산출물 | 용도 | 분량 |
|---|---|---|
| `output/일본어면접_평가시트_학생배부용_A4.pdf` | 면접 전 학생에게 1인 1매 배부. 학생은 이름·면접순번만 기입하고, 면접관이 그 종이에 그대로 채점한다. **한국어 + 일본어.** | A4 1p |
| `output/일본어면접_평가시트_학생배부용_JP-NE_A4.pdf` | 위와 동일한 시트의 **일본어 + 네팔어 병기판.** 학생이 읽고 기입하는 쪽을 네팔어로 받쳐, 현지에서 이름·면접순번 오기입을 줄이는 용도. | A4 1p |
| `output/일본어면접_질문지_면접관용_KO.pdf` | **면접관 전용. 학생에게 배부 금지.** 6분류 × 10문항 = 60문항 (일본어 원문 + 한국어 해석) | A4 4p |

## 평가 설계

- 평가영역 6개 — ①자기소개·기본회화 ②일본어 학습·일본 이해 ③일본 취업동기·장래계획
  ④일상생활·문제해결 ⑤직장 커뮤니케이션·지시 이해 ⑥현장 안전·보고
  - ⑥은 介護·宿泊 어느 직종에도 쓸 수 있도록 직종 무관 공통 문항으로 구성했다.
- 난이도는 **N4 균일**(영역 내 편차를 두지 않는다).
- 영역당 5점 × 6영역 = **30점 만점**. A 26~30 / B 22~25 / C 18~21 / D 17점 이하.
- ⑤ 또는 ⑥이 0~1점이면 총점과 무관하게 별도 검토 대상으로 표기한다.
- 질문지 1p의 **출제번호 랜덤 배정표**는 고정 시드(`random.Random(20260818)`)로 생성한다.
  시드를 바꾸면 배정표가 통째로 바뀌므로, 이미 인쇄해 운용 중인 회차에서는 건드리지 않는다.

## 빌드

```sh
python3 scripts/interview-sheets/build.py          # HTML 생성 + PDF 렌더 → output/
python3 scripts/interview-sheets/build.py --html   # HTML만 (playwright 불필요)
```

- 로고는 `company/public/brand/logo-black.svg`(공식 흑백 락업)를 읽어 data URI 로 인라인한다.
  브랜드 에셋을 다시 export 하면 PDF도 다시 빌드해야 한다.
- PDF 렌더는 node + playwright(chromium)를 쓴다. 없으면 `--html` 로 만든 뒤
  브라우저에서 인쇄 → PDF 저장(A4, 배경 그래픽 켜기)으로 대체할 수 있다.
- 렌더 환경에 CJK 글리프(Noto Sans CJK KR / JP)와 데바나가리 글리프가 있어야 한다.
  데바나가리는 `Noto Sans Devanagari` → `Kohinoor Devanagari` → `Devanagari Sangam MN` 순으로 폴백하며,
  macOS 는 뒤의 둘을 기본 탑재하므로 별도 설치 없이 렌더된다. Debian/Ubuntu 는 `fonts-noto-core` 를 설치한다.
- 중간 산출물은 `scripts/interview-sheets/.build/` 에 떨어지며 git 추적 대상이 아니다.

## 문항 수정

문항 데이터는 `build.py` 상단 `CATS` 리스트에 `(번호, 한국어 영역명, 일본어 영역명, 확인 포인트, [(일본어 질문, 한국어 해석), ...])`
형태로 들어 있다. 영역당 10문항을 유지해야 출제번호 배정표(1~10)와 어긋나지 않는다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `build.py` | 문항 데이터(`CATS`) + 질문지 HTML 생성 + 렌더 오케스트레이션 |
| `sheet.template.html` | 평가시트 한국어+일본어판 템플릿. `{{LOGO}}` 자리에 로고 data URI 가 치환된다. |
| `sheet.ne.template.html` | 평가시트 일본어+네팔어판 템플릿. 레이아웃은 동일하고 문구만 다르다. |

두 평가시트 템플릿은 **레이아웃이 같으므로 한쪽을 고치면 다른 쪽도 같이 고쳐야 한다.**
